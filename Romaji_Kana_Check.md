# ローマ字かな変換 確認用チェックリスト

今回の修正（capture.lua のバッチ化・target.lua の削除範囲計算変更・
`<C-g>`/`<Left>`/`<Right>` の扱い変更）が、通常のローマ字かな変換に
影響していないかを確認するための対応表です。

いずれも新しいバッファで `i`（挿入モード）に入ってから、オートペア等の
干渉が無い状態で、1文字ずつ普通に打鍵したときの結果を想定しています
（今回の変更が影響しうるのは主に「同一ティック内に複数キーが来た場合」
「`<C-g>`/`<Left>`/`<Right>` が割り込む場合」なので、まずは素の入力で
何も壊れていないことを確認いただくのが目的です）。

「一括入力」欄は、Vim のマクロ（`qq...q` で記録して `@q` で連続実行、
または `:normal!` 等）で複数キーを一気に流し込んだ場合の想定結果です。
今回のバッチ化は「同一ティック内に複数キーが来ても書き込みが1回に
まとまる」という変更なので、余裕があればマクロでの一括入力も試して
いただけると、より強く確認できます（必須ではありません）。

## 6. ん

| ローマ字 | 期待されるかな | 備考                                                   |
| -------- | -------------- | ------------------------------------------------------ |
| nn       | ん             | 明示的な「ん」確定                                     |
| kanda    | かんだ         | n+子音（母音でもyでもない）で自動的にん確定            |
| kannji   | かんじ         | 同上、nn重ねでも可                                     |
| hon      | ほn            | 末尾の単独nは確定せず未確定のまま残る（本来の仕様）    |
| honya    | ほにゃ         | n+ya は「ん」+「や」ではなく「にゃ」行として解釈される |

skkeleton・fcitx5-skk でも同じ結果になることを確認した。実装間で共通の仕様。
「ほんや」と入力したい場合は honnya と打鍵する

## 12. オートペア併用時の確認（今回のメイン修正の総仕上げ）

nvim-autopairs 有効な状態で、以下を確認した。
`_` はカーソル位置を示す

| ひらがなモードで続けて打鍵 | 期待される結果 |
| -------------------------- | -------------- |
| いろは(                    | いろは(_)      |
| いろは[                    | いろは「_」    |
| z(                         | （_)           |

| 全角英数モードで続けて打鍵 | 期待される結果 |
| -------------------------- | -------------- |
| ABC(                       | ＡＢＣ（_）    |
| ABC"                       | ＡＢＣ＂_＂    |
